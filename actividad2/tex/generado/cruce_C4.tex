\begin{itemize}[nosep]
  \item Variable independiente $X$: Interés en posgrado.
  \item Variable dependiente $Y$: Oferta FCyT afín.
  \item Población: todos los titulados ($N = 148$). Criterio ARCU-SUR: 2.4.1. Nivel de significancia $\alpha = 0.05$.
  \item $H_0$: Las variables «Interés en posgrado» (X) y «Oferta FCyT afín» (Y) son independientes.
  \item $H_1$: Existe dependencia significativa entre las variables «Interés en posgrado» (X) y «Oferta FCyT afín» (Y).
