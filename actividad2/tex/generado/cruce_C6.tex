\subsubsection*{C6. Concordancia formación–mercado $\times$ tiempo al primer empleo}

\textit{Paso 1. Describir el problema.} Determinar si percibir la formación alineada con los requerimientos del mercado se asocia con un menor tiempo para obtener el primer empleo.

\begin{itemize}[nosep]
  \item Variable independiente $X$: Concordancia.
  \item Variable dependiente $Y$: Tiempo al primer empleo.
  \item Población: trabajan en una organización ($N = 74$). Criterio ARCU-SUR: 3.2.3. Nivel de significancia $\alpha = 0.05$.
  \item $H_0$: Las variables «Concordancia» (X) y «Tiempo al primer empleo» (Y) son independientes.
  \item $H_1$: Existe dependencia significativa entre las variables «Concordancia» (X) y «Tiempo al primer empleo» (Y).
\end{itemize}

No se rechaza $H_0$: con estos datos, «Tiempo al primer empleo» no depende de «Concordancia».

\textit{Recomendación.} El tiempo al primer empleo no depende de la concordancia percibida: la inserción rápida se explica por otros factores, como que muchos titulados ya trabajaban antes de titularse.
