\subsubsection*{C3. Formación complementaria $\times$ remuneración}

\textit{Paso 1. Describir el problema.} Determinar si la formación complementaria se asocia con el nivel de remuneración, como sustento para la oferta de actualización profesional y posgrado.

\begin{itemize}[nosep]
  \item Variable independiente $X$: Formación complementaria.
  \item Variable dependiente $Y$: Remuneración.
  \item Población: trabajan en una organización ($N = 108$). Criterio ARCU-SUR: 2.4.1. Nivel de significancia $\alpha = 0.05$.
  \item $H_0$: Las variables «Formación complementaria» (X) y «Remuneración» (Y) son independientes.
  \item $H_1$: Existe dependencia significativa entre las variables «Formación complementaria» (X) y «Remuneración» (Y).
\end{itemize}

No se rechaza $H_0$: con estos datos, «Remuneración» no depende de «Formación complementaria».

\textit{Recomendación.} La formación complementaria no se asocia con la remuneración en esta muestra: la oferta de posgrado debe justificarse por actualización y pertinencia, no por una promesa salarial.
